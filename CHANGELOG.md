# Changelog

Все заметные изменения проекта фиксируются здесь. Версии сверяются
командой `agip status` / `agip update` с файлом `VERSION` в репозитории.

## 1.1.1

- `agip-install.sh` и `agip-uninstall.sh` стали полностью самостоятельными:
  никакой зависимости от `AGIP-Manager.sh`, работают офлайн. Установка
  копирует файлы из папки `files/` рядом со скриптом, удаление просто
  чистит известные пути — оба без единого сетевого вызова.
- `AGIP-Manager.sh` не менялся по логике, остаётся онлайн-инструментом
  (install/update/status/remove через GitHub) для тех, у кого есть
  интернет на роутере.

## 1.1.0

- Мониторинг нескольких WAN-интерфейсов одновременно (dual-WAN/два и более
  WAN-портов): `list interface` вместо одиночного `option interface`,
  у каждого интерфейса свой счётчик неудачных попыток.
- Выбор интерфейсов в LuCI — выпадающий список с множественным выбором
  (`form.MultiValue`), заполняется реальными интерфейсами из
  `Сеть → Интерфейсы`.
- Редактируемый список "серых" подсетей (`list gray_subnet`, CIDR),
  по умолчанию корректно заполнен для Ростелекома (в т.ч. CGNAT‑пул
  `100.64.0.0/10`).
- `AGIP-Manager.sh`: слежение за версией (`VERSION`), `agip update`
  сравнивает установленную и доступную версии и пропускает обновление,
  если версия та же (`agip update force` — обновить принудительно).
- `AGIP-Manager.sh`: проверка содержимого каждого скачанного файла перед
  установкой (совпадение ожидаемого начала файла) — качаются во временный
  файл, и только при успешной проверке подменяют боевой файл; при
  несовпадении обновление прерывается, старый файл остаётся нетронутым.
- Отдельные `agip-install.sh` и `agip-uninstall.sh` поверх общего менеджера.
- Раздел меню LuCI перенесён в **Службы**, название — **AntiGrayIP**,
  интерфейс на русском и английском.

## 1.0.0

- Первая версия: служба `procd`, проверка одного WAN-интерфейса на
  приватный/CGNAT адрес, автоматический `ifdown`/`ifup`, опциональная
  эскалация до полной перезагрузки, LuCI-страница, JSON-модуль меню,
  ACL для rpcd, установочный и деинсталляционный скрипты.
